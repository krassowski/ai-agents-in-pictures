---
name: commit-message
description: Write a commit message for a change.
---

1. The first line says what the change does, in at most 50 characters. It starts with a verb, such as Fix, Add or Remove.
2. Then comes an empty line.
3. Then one or two sentences say why the change was needed.
4. The last line is "Fixes" and the issue number, when the change fixes an issue.
